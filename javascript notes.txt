let --> declares a variable
*** cannot use "let" more than once per variable, if needing to change value of variable simply declare it's value without the "let" command

ex. let message = "hello";
	message = "hello world!";

there exists a practice of using "const" to create aliases for other values that are difficult to remember or refer too.

ex. const COLOR_RED = "#F00";

it's a lot easier to apply COLOR_RED than it is to remember the hexadecimal value for the color red. All caps names for constants is, in best practice, only used for aliases of "hard-coded" values.
*** hard-coded refers to values that are known prior to any code being executed. so it would be reasonable to use:
	const BIRTHDAY = '07.01.1995'

++ before a variable returns the new value while putting it after returns the old value
ex. let a = 2;
	++a returns 3		a++ returns 2, then increases the value
this is useful because we might want to use the new value or old value after the increment, so choosing the correct one enables that

' and " do the same thing, declaring the string

***can also add line breaks using \n within ' or " strings

To actually include ', `, or " as part of a string, you can:
 - Define the string using one of the other characters to define the string
